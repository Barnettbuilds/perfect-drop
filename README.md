# Perfect Drop — browser prototype

A single-file HTML5 arcade game prototype designed for mobile browsers.

## Try it
Open `index.html` in a modern browser. On an iPhone, the easiest route is to host this file on a static web host (for example, a GitHub Pages or Netlify site) and open its HTTPS address in Safari.

## Controls
- Tap the game area or DROP BLOCK to place a block.
- Press PLAY AGAIN or ↻ to restart.
- Space bar also drops a block on desktop.

## Current features
- One-touch stacking gameplay
- Increasing movement speed
- Perfect-drop feedback and particle effects
- Local personal-best score
- Responsive mobile layout and vibration feedback where supported
